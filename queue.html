Queue Visualizer (FIFO)

Queue is First In First Out. First element inserted is removed first. Like a line of people.

Ready. Enqueue values. Capacity is 8.

Queue Display

Status: Front = Empty | Size = 0 / 8 | Is Empty? Yes | Is Full? No

How it works

  • Enqueue: Add element at rear
  • Dequeue: Remove element from front
  • Front: See front element without removing
  • Time complexity: O(1)
Backend: backend/visualizers.cpp -> class Queue { enqueue(), dequeue(), getFront(), isEmpty(), isFull() } Frontend: js/queue.js sends operations to the C++ backend and renders the returned queue state.
