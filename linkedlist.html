Linked List Visualizer (Singly)

Linked List is collection of nodes. Each node has data and pointer to next node. HEAD points to first node.



Ready. Insert nodes to build linked list.

How it works

  • Insert: Create new node, link pointers
  • Delete: Update pointer to skip node
  • Search: Traverse from HEAD one by one
  • Display: Traverse and show all nodes -> NULL
Backend: backend/visualizers.cpp -> struct Node, class LinkedList { insertAtBeginning(), insertAtEnd(), delete..., search(), display() } Frontend: js/linkedlist.js sends operations to the C++ backend and renders returned node data.
