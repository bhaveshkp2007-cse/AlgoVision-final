How it works

  • Hash Function: hash = (sum of char codes) % 8
  • Insert: Calculate bucket, add to chain. If key exists, update value.
  • Search: Go to bucket, check chain for key.
  • Delete: Remove from chain.
  • Collision: Multiple keys at same bucket stored as chain.
Backend: backend/visualizers.cpp -> class HashMap { hashFunction(), insert(), search(), remove(), display() } uses Separate Chaining. Frontend: js/hashmap.js sends operations to the C++ backend and renders returned buckets.
